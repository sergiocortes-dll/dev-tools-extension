Carpeta raíz de extracción

Elige la carpeta donde se guardarán los reportes. Dentro de ella se crea automáticamente la estructura {repo}/{rama-destino}/{rama-origen}/{fecha}__{ronda}.md para comentarios de PR, y transcripciones/{nombre-llamada}/transcription.txt para transcripciones.

Ninguna carpeta configurada todavía.
Esta función requiere Chrome o Edge (File System Access API). No funciona en Firefox.
